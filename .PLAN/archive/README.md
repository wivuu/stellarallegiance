# .PLAN/archive/

Completed handoff notes, kept for history only. `old/` is the prototype-era build-order handoff
from before the native sim server existed; `base-building/` covers the constructor/base-building
work; `tech-paths/` is the four-phase (A-D) tech-tree port. All of it has shipped, and all of it
references design files (`.PLAN/0N-*.md`) and phase numbering that no longer exist — read these as
a record of what was done and why, never as current spec. The live roadmap is
[`../README.md`](../README.md); the live flight-model reference is
[`../ship_movement/`](../ship_movement/), which is deliberately **not** archived.
